## 電話鈴聲修改

原版 `lib/nubo-call-tones.ts` 使用 425 Hz 正弦波響 800ms、間隔 400ms 共兩次。
館主上傳 `freesound_community-ring-tone-68676.mp3` 為 30.048 秒、24kHz、雙聲道；每約 6 秒有一次電話響鈴。已於測試端擷取前 2.7 秒並加淡出，`nubo-phone-ring-preview.mp3` 供確認。

**關鍵缺項：** GitHub 連接器的一般 create/update file 動作只支援 UTF-8 文字，本測試分支尚未納入該 MP3 **二進位音檔**。因此現在不可以說音效已替換成功。待確定 Freesound 素材授權及取得二進位上傳管道後，將短版音檔放在：
`public/audio/nubo-phone-ring.mp3`

音檔一旦存在，`playNuboCallTones()` 即優先播放該真實鈴聲，並在 4 秒內停止，然後按既有流程連接 Gemini Live／OpenAI Realtime；音檔缺失、播放被限制或離線時仍有舊音作為備援。正式部署前須在 iPad Safari、Chrome、Android WebView 測試，不可只靠程式碼審查。

## 驗收清單

1. 按撥號鍵，只播放上傳來源的短版鈴聲；無 425Hz 嗶嗶音，無重疊兩次播放。
2. 鈴聲 4 秒內結束，不影響原本麥克風授權與 WebRTC/WebSocket 建連。
3. 針對 CD、CT、CK、PD、PT、PK、PS、RD、RT、RK、NF、NV 的週五與週六價逐一對照原圖，尤其 PT 週六 2780。
4. 「今天還有房？」必須先確認日期、人數並取得最新 PMS 庫存，不可依價格表推論有房。
5. 「從臺中火車站怎麼來？」先提供公車 5／132 到中友百貨或臺中科大附近之策略，班次與實際車程要查當日官方資料，不可猜測時間。
6. 不得引用舊品牌房價、停車條件或尚未驗證的新寶官網內容。
7. 暫勿部署到正式 `codex/nubosci-voice-prod-20261117`，也勿改寫 PMS 或旅客訂單。
