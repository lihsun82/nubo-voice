# NUBO Token Saver Standby V1

This release adds local silence gating, automatic Gemini Live shutdown after 45 seconds without speech, foreground wake-word standby, and immediate standby commands.

Wake words: 嗨 NUBO, ha NUBO, NUBO, 兄弟, 有人嗎.

Sleep words: 閉嘴, 安靜, 退下, 不要講話, 停止說話.

LINE webhook and stable LINE control code are not modified.
